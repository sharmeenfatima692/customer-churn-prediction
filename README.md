# AI-Powered Customer Intelligence & Churn Prediction

## 📌 Project Overview

This project analyzes customer behavior and predicts customer churn using Python, data analysis, and machine learning techniques.

The goal is to identify customers who are more likely to leave the company and provide business recommendations to improve customer retention.

## 🎯 Objectives

- Analyze customer churn patterns
- Identify factors affecting customer churn
- Build machine learning classification models
- Compare model performance
- Generate actionable business insights

## 📊 Dataset

The project uses a Telco Customer Churn dataset containing:

- 7,043 customer records
- 33 features
- Customer demographics
- Services and subscription information
- Contract details
- Payment information
- Churn status

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- Jupyter Notebook

## 🔍 Analysis Performed

The project includes:

- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Customer churn rate analysis
- Contract type analysis
- Internet service analysis
- Payment method analysis
- Customer tenure analysis
- Feature importance analysis

## 🤖 Machine Learning Models

Three classification models were evaluated:

1. Logistic Regression
2. Random Forest
3. XGBoost

## 📈 Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | **80.27%** |
| Random Forest | **80.13%** |
| XGBoost | **78.57%** |

Logistic Regression achieved the highest accuracy among the three tested models.

## 💡 Key Insights

- Approximately **26.54%** of customers have churned.
- Month-to-month customers show the highest churn risk.
- Fiber optic customers have a relatively high churn rate.
- Electronic-check users show higher churn.
- Customer churn generally decreases as tenure increases.
- Tenure, total charges, contract type, dependents, and internet service are important factors associated with churn.

## 💼 Business Recommendations

- Encourage month-to-month customers to move to longer-term contracts.
- Provide retention offers for new customers.
- Investigate customer dissatisfaction among fiber optic users.
- Review the electronic-check payment experience.
- Promote services such as online security and technical support.
- Focus retention strategies on customers with shorter tenure.
